`deployed-firestore-134a97cf.rules` is a byte-exact copy of the Firestore
ruleset that production (`parkqueen-46475363-ccf36`) served when it was read
on 2026-11-11 (t660u, Firebase MCP `firebase_get_security_rules`, content
only). SHA-256:

    134a97cf8e25f2f8848ff4d2c0ff65ff5dd83434f1690901b4ba7dffe403810b

It matches no committed `firestore.rules` blob (it carries an uncommitted
`users/{uid}/private/carLocation` block). The ruleset name and createTime
were not readable and are UNVERIFIED.

Use: `firestore.rules.test.mixed-version-deployed.ts` loads it into the local
rules emulator to replay Oct 16 client writes. It is never deployed;
`firebase.json` still points at `firestore.rules`. Do not edit this file. A
new production snapshot must get a new file name and digest.
